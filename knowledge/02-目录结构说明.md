# Joplin 项目目录结构说明

## 根目录结构

```
joplin/
├── packages/          # 所有子包（核心代码）
├── readme/            # 项目文档
├── Assets/            # 资源文件（图标、图片等）
├── knowledge/         # 项目知识库（本文档所在目录）
├── package.json       # 根 package.json（定义工作区和脚本）
├── lerna.json         # Lerna 配置
├── yarn.lock          # Yarn 锁定文件
├── tsconfig.json      # TypeScript 配置
└── README.md          # 项目说明
```

## packages/ 目录详解

`packages/` 目录包含所有核心代码包，采用 Monorepo 结构：

### 应用程序包

| 包名 | 说明 | 技术栈 |
|------|------|--------|
| **app-cli** | 命令行终端应用 | terminal-kit, Node.js |
| **app-desktop** | 桌面应用程序 | Electron, React, TypeScript |
| **app-mobile** | 移动应用程序（iOS/Android） | React Native, TypeScript |
| **app-clipper** | 浏览器扩展（Web Clipper） | WebExtensions API, React |

### 核心库包

| 包名 | 说明 | 主要功能 |
|------|------|----------|
| **lib** | 核心库（最重要） | 数据库、同步、加密、导入/导出、业务逻辑 |
| **renderer** | Markdown 和 HTML 渲染器 | 笔记渲染引擎 |
| **editor** | 编辑器组件 | 富文本编辑器实现 |
| **utils** | 工具函数库 | 通用工具函数 |

### 服务器相关

| 包名 | 说明 |
|------|------|
| **server** | Joplin Server 应用 | Node.js REST API 服务器 |
| **transcribe** | 手写识别服务器 | AI 手写文本识别服务 |

### 插件系统

| 包名 | 说明 |
|------|------|
| **plugins** | 插件示例和工具 |
| **default-plugins** | 默认插件集合 |
| **generator-joplin** | 插件生成器 |
| **plugin-repo-cli** | 插件仓库 CLI 工具 |

### 转换器和工具

| 包名 | 说明 |
|------|------|
| **onenote-converter** | OneNote 转换器（Rust 实现） |
| **turndown** | HTML 转 Markdown |
| **turndown-plugin-gfm** | GitHub Flavored Markdown 插件 |
| **pdf-viewer** | PDF 查看器组件 |

### Fork 包

这些是对第三方包的定制版本：

- **fork-htmlparser2**：HTML 解析器
- **fork-sax**：XML/HTML 解析器
- **fork-uslug**：URL slug 生成器

### 构建和工具包

| 包名 | 说明 |
|------|------|
| **tools** | 构建工具和脚本 |
| **doc-builder** | 文档构建工具 |
| **generate-plugin-doc** | 插件文档生成器 |
| **htmlpack** | HTML 打包工具 |

### React Native 相关

- **react-native-alarm-notification**：闹钟通知功能
- **react-native-saf-x**：安全存储扩展

## 关键配置文件

### 根目录配置文件

- **package.json**：定义工作区、脚本和依赖
- **lerna.json**：Lerna 配置（版本管理）
- **tsconfig.json**：TypeScript 编译配置
- **yarn.lock**：依赖版本锁定
- **devbox.json**：开发环境配置

### Docker 相关

- **docker-compose.db-dev.yml**：开发数据库配置
- **docker-compose.server-dev.yml**：开发服务器配置
- **docker-compose.server.yml**：生产服务器配置
- **Dockerfile.server**：服务器 Docker 镜像
- **Dockerfile.transcribe**：转录服务 Docker 镜像

## 目录组织原则

1. **Monorepo 结构**：所有相关代码都在一个仓库中
2. **包分离**：每个功能模块都是独立的包
3. **共享代码**：`lib` 包被所有应用共享
4. **平台特定**：不同平台的 UI 代码分离，但共享后端逻辑

## 重要说明

- **lib 包**：这是最重要的包，包含所有核心业务逻辑，被所有应用程序共享
- **packages/*/package.json**：每个包都有自己的 package.json
- **TypeScript**：大部分代码使用 TypeScript 编写，编译后的 .js 文件与 .ts 文件在同一目录
- **测试文件**：测试文件通常命名为 `*.test.ts`，与源文件在同一目录
