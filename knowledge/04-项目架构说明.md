# Joplin 项目架构说明

## 整体架构

Joplin 项目围绕三个主要组件组织：

1. **用户应用程序**：桌面版、移动版和 CLI 版本
2. **Joplin Server**：同步服务器
3. **Web Clipper**：浏览器扩展 浏览器插件

## 应用程序架构

所有用户应用程序（桌面、移动、CLI）共享相同的架构和后端代码，主要区别在于 UI 框架和系统集成。

### 架构层次

```
┌─────────────────────────────────────┐
│          Frontend (UI)               │
│  - Desktop: Electron + React         │
│  - Mobile: React Native             │
│  - CLI: terminal-kit                │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│          Backend (共享)              │
│  ┌───────────────────────────────┐   │
│  │      Services Layer          │   │
│  │  - Search Engine             │   │
│  │  - Plugin System             │   │
│  │  - Synchronizer              │   │
│  └───────────────────────────────┘   │
│              ↓                       │
│  ┌───────────────────────────────┐   │
│  │      Models Layer             │   │
│  │  - Note Model                 │   │
│  │  - Notebook Model             │   │
│  │  - Tag Model                  │   │
│  └───────────────────────────────┘   │
│              ↓                       │
│  ┌───────────────────────────────┐   │
│  │      Database (SQLite)        │   │
│  │  - Local storage              │   │
│  │  - Settings                   │   │
│  │  - Cache                      │   │
│  └───────────────────────────────┘   │
└─────────────────────────────────────┘
```

### 核心组件说明

#### 1. Services Layer（服务层）

提供高级功能：

- **Search Engine** (`packages/lib/services/search`): 全文搜索功能
- **Plugin System** (`packages/lib/services/plugins`): 插件系统
- **Synchronizer** (`packages/lib/Synchronizer.ts`): 同步引擎

#### 2. Models Layer（模型层）

位于服务和数据库之间，提供高级抽象：

- **Note Model**: 笔记数据模型
- **Notebook Model**: 笔记本数据模型
- **Tag Model**: 标签数据模型
- **Resource Model**: 资源（附件）模型

#### 3. Database（数据库）

所有应用使用本地 SQLite 数据库存储：
- 笔记内容
- 设置
- 缓存
- 同步状态

## 桌面应用架构

### 技术栈

- **框架**: Electron
- **前端**: React + TypeScript
- **后端**: Node.js
- **样式**: SCSS

### 目录结构

```
app-desktop/
├── main.ts              # Electron 主进程入口
├── gui/                 # React UI 组件
│   ├── components/      # React 组件
│   ├── screens/         # 屏幕/页面
│   └── utils/           # UI 工具函数
├── services/            # 服务层
├── commands/           # 命令处理
└── utils/              # 工具函数
```

### 进程模型

- **主进程** (`main.ts`): Electron 主进程，处理窗口、菜单等
- **渲染进程**: React 应用运行在渲染进程中

## 移动应用架构

### 技术栈

- **框架**: React Native
- **语言**: TypeScript
- **JavaScript 引擎**: Hermes
- **原生代码**: iOS (Swift/Objective-C), Android (Java/Kotlin)

### 目录结构

```
app-mobile/
├── app.ts               # 应用入口
├── screens/             # 屏幕组件
├── components/          # React Native 组件
├── services/            # 服务层（共享 lib）
├── android/             # Android 原生代码
└── ios/                 # iOS 原生代码
```

## CLI 应用架构

### 技术栈

- **框架**: terminal-kit
- **语言**: TypeScript
- **运行时**: Node.js

### 特点

- 纯命令行界面
- 共享相同的后端逻辑

## Joplin Server 架构

### 组件

```
┌─────────────────────────────────────┐
│         Nginx (反向代理)            │
│      TLS 终止、负载均衡              │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│      Joplin Server (Node.js)        │
│      REST API                        │
└─────────────────────────────────────┘
         ↓                    ↓
┌─────────────────┐  ┌─────────────────┐
│  PostgreSQL      │  │   AWS S3        │
│  - 元数据        │  │   - 内容存储     │
│  - 用户账户      │  │   - 附件        │
│  - 访问日志      │  │                 │
└─────────────────┘  └─────────────────┘
```

### 技术栈

- **应用**: Node.js + TypeScript
- **数据库**: PostgreSQL（元数据）
- **存储**: AWS S3 或文件系统（内容）
- **反向代理**: Nginx（可选）

### API

Joplin Server 提供 REST API：
- 上传/下载笔记
- 同步操作
- 用户管理
- 共享功能

## Web Clipper 架构

### 技术栈

- **API**: WebExtensions API
- **UI**: React
- **通信**: 通过 HTTP 与桌面应用通信

### 工作流程

```
浏览器页面
    ↓
Web Clipper Extension
    ↓ (HTTP)
Desktop App (localhost)
    ↓
Local Database
```

## 同步架构

### 同步流程

1. **本地更改**：用户修改笔记
2. **立即上传**：几秒内上传到同步目标
3. **定期轮询**：每几分钟下载最新更改
4. **冲突处理**：自动合并或标记冲突

### 同步目标

支持多种同步目标：

- **Joplin Server**: 官方服务器
- **Nextcloud**: 自托管
- **Dropbox**: 云存储
- **OneDrive**: 云存储
- **WebDAV**: 标准协议

### 同步组件

- **Synchronizer.ts**: 核心同步逻辑
- **SyncTarget*.ts**: 各同步目标的实现
- **FileApi**: 文件操作抽象

### 端到端加密（E2EE）

- 客户端加密
- 服务器无法读取内容
- 支持多种同步目标

## 插件系统架构

### 插件类型

1. **Content Scripts**: 修改编辑器行为
2. **View Plugins**: 自定义视图
3. **Menu Plugins**: 添加菜单项
4. **Settings Plugins**: 设置页面

### 插件 API

- **Joplin API**: 访问笔记、设置等
- **Plugin API**: 注册命令、菜单等
- **Content Script API**: 修改编辑器

## 数据模型

### 核心实体

- **Note**: 笔记
- **Notebook**: 笔记本（可嵌套）
- **Tag**: 标签
- **Resource**: 资源（图片、附件）
- **Setting**: 设置

### 关系

```
Notebook
  ├── Note (多个)
  │     ├── Tag (多个)
  │     └── Resource (多个)
  └── Notebook (子笔记本)
```

## 渲染系统

### Markdown 渲染

- **Renderer** (`packages/renderer`): Markdown 到 HTML 转换
- **Editor** (`packages/editor`): 富文本编辑器
- **插件支持**: 可扩展渲染

### 渲染流程

```
Markdown 文本
    ↓
Parser (markdown-it)
    ↓
AST (抽象语法树)
    ↓
HTML 渲染
    ↓
样式应用
```

## 安全架构

### 加密

- **E2EE**: 端到端加密
- **本地加密**: SQLite 数据库可选加密
- **传输加密**: HTTPS/TLS

### 认证

- **Joplin Server**: 用户名/密码 + MFA
- **第三方同步**: OAuth 或 API 密钥

## 性能优化

### 客户端

- **SQLite**: 快速本地查询
- **索引**: 数据库索引优化
- **缓存**: 渲染结果缓存
- **增量同步**: 只同步更改

### 服务器

- **PostgreSQL**: 高效查询
- **S3**: 对象存储优化
- **CDN**: 静态资源分发（可选）

## 扩展性

### 水平扩展

- **Joplin Server**: 可部署多个实例
- **负载均衡**: Nginx 分发请求
- **数据库**: PostgreSQL 支持集群

### 垂直扩展

- **缓存**: Redis（可选）
- **CDN**: 静态资源加速
- **数据库优化**: 索引和查询优化

## 开发架构原则

1. **代码复用**: 共享 `lib` 包
2. **平台抽象**: 平台特定代码隔离
3. **模块化**: 清晰的包边界
4. **类型安全**: TypeScript 类型检查
5. **测试**: 单元测试和集成测试

## 部署架构

### 客户端部署

- **桌面**: Electron 打包
- **移动**: App Store / Google Play
- **CLI**: npm 包

### 服务器部署

- **Docker**: 容器化部署
- **Docker Compose**: 开发环境
- **Kubernetes**: 生产环境（可选）

## 监控和日志

### 客户端

- **调试模式**: 详细日志
- **错误报告**: 用户可选的错误报告

### 服务器

- **访问日志**: 记录 API 调用
- **错误日志**: 记录错误和异常
- **性能监控**: 响应时间等指标
