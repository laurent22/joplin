# Joplin 项目概述

## 项目简介

Joplin 是一个免费、开源的笔记和待办事项应用程序，可以处理大量笔记并组织成笔记本。笔记支持搜索、复制、标记和修改，可以直接在应用程序中操作，也可以使用自己的文本编辑器编辑。笔记采用 Markdown 格式。

### 核心特性

- **离线优先**：所有数据都保存在本地设备上，确保即使没有网络连接也能访问笔记
- **端到端加密同步**：支持与 Nextcloud、Dropbox、OneDrive 和 Joplin Cloud 等云服务进行安全同步
- **多平台支持**：Windows、Linux、macOS、Android 和 iOS
- **Web Clipper**：浏览器扩展，可保存网页和截图
- **全文搜索**：所有平台都支持全文搜索
- **插件系统**：支持自定义插件和主题

## 项目结构

Joplin 采用 **Monorepo** 架构，使用以下工具管理：

- **Yarn Workspaces**：管理多个包的依赖关系
- **Lerna**：用于发布和管理版本
- **TypeScript**：主要开发语言

### 技术栈

- **运行时**：Node.js >= 18
- **包管理**：Yarn 4.9.2
- **前端框架**：
  - Desktop: Electron + React
  - Mobile: React Native
  - CLI: terminal-kit
- **后端**：Node.js
- **数据库**：
  - 客户端：SQLite（本地存储）
  - 服务器：PostgreSQL（Joplin Server）

## 主要组件

项目主要包含三个核心组件：

1. **用户应用程序**：桌面版、移动版和 CLI 版本
2. **Joplin Server**：用于多设备同步的服务器
3. **Web Clipper**：浏览器扩展
