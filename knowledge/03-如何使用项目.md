# Joplin 项目使用指南

## 环境要求

### 必需依赖

- **Node.js**: >= 18
- **Yarn**: 4.9.2（项目会自动使用）
- **Git**: 用于克隆仓库

### 可选依赖

- **Docker**: 用于运行 Joplin Server（可选）
- **PostgreSQL**: 用于 Joplin Server 生产环境（可选）
- **Rust**: 如果需要在 `onenote-converter` 包上工作

### 使用 Devbox（推荐）

项目提供了 `devbox.json` 配置文件，可以自动安装所有依赖：

```bash
# 安装 devbox（如果还没有）
# macOS
brew install devbox

# Linux
curl -fsSL https://get.jetify.com/devbox | bash

# 进入开发环境
devbox shell
```

## 初始设置

### 1. 克隆仓库

```bash
git clone https://github.com/laurent22/joplin.git
cd joplin
```

**重要**：确保项目路径中不包含空格，否则构建可能失败。

### 2. 安装依赖

```bash
yarn install
```

这会安装所有包的依赖。首次安装可能需要较长时间。

### 3. 构建 TypeScript

```bash
yarn tsc
```

或者使用 watch 模式（推荐开发时使用）：

```bash
yarn watch
```

## 运行应用程序

### 桌面应用程序

```bash
cd packages/app-desktop
yarn start
```

**注意**：在 Windows 上，建议使用常规命令提示符，不支持 WSL。

### CLI 应用程序

```bash
cd packages/app-cli
yarn start
```

### 移动应用程序

#### Android

首先需要设置 React Native 开发环境，参考 [React Native 环境设置](https://reactnative.dev/docs/environment-setup)。

```bash
cd packages/app-mobile/android
./gradlew installDebug
# Windows: gradlew.bat installDebug
```

#### iOS

```bash
# 安装 CocoaPods 依赖
cd packages/app-mobile/ios
pod install

# 或者使用环境变量自动安装
RUN_POD_INSTALL=1 yarn install

# 然后在 Xcode 中打开
open ios/Joplin.xcworkspace
```

启动 Metro bundler：

```bash
cd packages/app-mobile
yarn start
```

#### Web 版本

```bash
cd packages/app-mobile
yarn serve-web          # 开发服务器（端口 8088）
yarn serve-web-hot-reload  # 热重载模式
yarn web                # 构建生产版本
```

### Web Clipper

```bash
cd packages/app-clipper/popup
npm run watch
```

然后在浏览器中加载扩展：
- **Chrome**: 打开 `chrome://extensions/`，启用开发者模式，加载解压的扩展
- **Firefox**: 打开 `about:debugging`，加载临时扩展

**注意**：开发模式的扩展只能连接到开发版本的桌面应用。

## 开发工作流

### 文件监听

在开发时，需要监听 TypeScript 文件变化：

```bash
# 从根目录运行
yarn watch
```

这会自动编译所有修改的 TypeScript 文件。

### 移动应用特殊说明

如果修改了笔记编辑器、查看器或其他 WebView 内容：

```bash
cd packages/app-mobile
yarn watchInjectedJs
```

### 运行测试

```bash
# 运行所有测试
yarn test

# 运行特定包的测试
cd packages/lib
yarn test

# 运行特定测试文件
yarn test markdownUtils

# 运行特定测试用例
yarn test markdownUtils --filter="should handle conflict"
```

### 代码检查

```bash
# 运行 linter
yarn linter

# 交互式修复
yarn linter-interactive

# CI 模式（静默）
yarn linter-ci
```

## 构建生产版本

### 并行构建（推荐）

```bash
yarn buildParallel
```

### 顺序构建

```bash
yarn buildSequential
```

### 构建特定应用

```bash
# 桌面应用
cd packages/app-desktop
yarn build

# CLI 应用
cd packages/app-cli
yarn build

# 移动应用
cd packages/app-mobile
yarn build:android  # Android
yarn build:ios      # iOS
```

## 运行 Joplin Server

### 使用 Docker（最简单）

```bash
# 1. 复制配置文件
cp .env-sample .env

# 2. 编辑 .env 文件，配置数据库等

# 3. 运行服务器（使用 SQLite，适合测试）
docker run --env-file .env -p 22300:22300 joplin/server:latest
```

### 使用 Docker Compose

```bash
# 开发环境
docker-compose -f docker-compose.server-dev.yml up

# 生产环境
docker-compose -f docker-compose.server.yml up
```

### 本地开发

```bash
cd packages/server
yarn install
yarn start
```

## 常用命令参考

### 根目录命令

| 命令 | 说明 |
|------|------|
| `yarn install` | 安装所有依赖 |
| `yarn watch` | 监听并编译 TypeScript |
| `yarn tsc` | 编译 TypeScript（不监听） |
| `yarn test` | 运行所有测试 |
| `yarn linter` | 代码检查 |
| `yarn buildParallel` | 并行构建所有包 |
| `yarn clean` | 清理构建文件 |

### 包特定命令

进入特定包目录后：

```bash
cd packages/app-desktop
yarn start      # 运行应用
yarn build      # 构建应用
yarn test       # 运行测试
yarn watch      # 监听文件变化
```

## 调试

### 桌面应用调试

```bash
cd packages/app-desktop
yarn start --debug
```

### 启用调试模式

在应用设置中启用调试模式，或设置环境变量：

```bash
DEBUG=1 yarn start
```

## 常见问题

### 构建失败

1. 确保路径中没有空格
2. 确保 Node.js 版本 >= 18
3. 清理并重新安装：

```bash
yarn clean
yarn install
```

### 移动应用问题

- **iOS**: 确保运行了 `pod install`
- **Android**: 确保 Android SDK 已正确安装
- **WebView**: 确保运行了 `yarn watchInjectedJs`

### 依赖问题

```bash
# 清理缓存
yarn cache clean

# 重新安装
rm -rf node_modules
yarn install
```

## 开发最佳实践

1. **使用 watch 模式**：开发时始终运行 `yarn watch`
2. **运行测试**：提交代码前运行相关测试
3. **代码检查**：使用 `yarn linter` 检查代码风格
4. **小步提交**：频繁提交小的更改
5. **阅读文档**：查看 `readme/dev/` 目录下的开发文档
