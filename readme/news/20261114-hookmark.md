# Joplin Now Works with Hookmark

Joplin now integrates with [Hookmark](https://hookproductivity.com), a macOS app that links information across your apps. From Joplin 3.7.21, you can link any Joplin note to PDFs, web pages, emails, files and more, and jump back to the note in one click.

To celebrate, Joplin is Hookmark's Partner of the Month for November 2026, and the Hookmark team is offering Joplin users 30% off Hookmark Pro (details below).

## What you can do

Hookmark creates two-way links between items in different Mac apps. With Joplin, you can:

- **Link a note to its sources.** Connect a Joplin note to the papers, web pages, emails, files and tasks it's about.
- **Create linked notes with Hook to New.** Make a new Joplin note straight from Hookmark, already linked to what you're working on, such as an AI chat or a project plan.
- **Jump back and forth.** From any linked item, open the matching Joplin note, and from a note, open everything linked to it.

Hookmark is a paid macOS app from CogSci Apps. Joplin itself stays free and open source, and nothing changes for users who don't use Hookmark.

## How it works

The Hookmark team contacted us in July after many of their users asked for Joplin support. To make it possible, Joplin 3.7 added two [x-callback-url](https://github.com/laurent22/joplin/pull/16041) actions: `getCurrentNote` returns the title and link of the open note, and `createNote` creates a note and returns the same. Any parameters in the `x-success` URL are passed back unchanged, so Hookmark always knows which request a reply belongs to.

Other apps can use these actions too, so this also makes Joplin easier to automate on macOS. Note that a security fix in early 3.7 builds broke the callbacks; this was [fixed](https://github.com/laurent22/joplin/pull/16497) in 3.7.21, so please update if you're on an older version.

Many thanks to Bi Ling and Luc at CogSci Apps for their clear requirements and quick testing.
